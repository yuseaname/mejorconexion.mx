Respuesta Rápida

Una clínica o consultorio en México necesita mínimo 100 Mbps fibra simétrica para operar expediente clínico electrónico, videollamadas, PACS (imágenes médicas) y TPV sin cortes. El mejor proveedor es Totalplay fibra desde $399 MXN/mes por 200 Mbps simétrico. Para clínicas medianas con múltiples consultorios recomiendo 500 Mbps simétrico ($549/mes). Para hospitales y clínicas grandes, enlaces dedicados empresariales con SLA desde $1,500-$5,000/mes. La privacidad y seguridad de datos médicos exige redes cifradas y separación de tráfico.

  • Mínimo viable: 100 Mbps fibra simétrica para consultorio pequeño = $399 MXN/mes
  • Recomendado: 500 Mbps fibra simétrica para clínica con 3-5 consultorios = $549 MXN/mes
  • Crítico: red separada para datos médicos vs WiFi de sala de espera
  • Compliance: usa cifrado WPA3 y VPN para acceso remoto a expedientes
  • Acción: nunca uses internet residencial para clínica; elige planes empresariales con SLA

Para entender por qué la fibra simétrica importa, lee qué es internet simétrico.

Por qué el internet es crítico en salud

Una clínica moderna depende del internet para:

  1. Expediente clínico electrónico (ECE): acceso a historial de pacientes, recetas, notas.
  2. Videollamadas y telemedicina: consultas remotas, especialmente tras la pandemia.
  3. PACS (Picture Archiving and Communication System): imágenes médicas (rayos X, resonancias, ultrasonidos) que pesan 50-500 MB por estudio.
  4. Sistema de gestión: citas, facturación electrónica (CFDI), inventario.
  5. TPV: cobro de consultas y procedimientos.
  6. Acceso a plataformas: receta electrónica, CNBV, IMSS, seguridad social.

Una caída de internet puede paralizar una clínica: sin expediente no puedes atender, sin PACS no puedes diagnosticar, sin TPV no puedes cobrar.

Configuración crítica: seguridad de datos médicos

Red 1: Datos médicos (ECE, PACS, TPV)

  • VLAN separada y cifrada
  • WPA3 Enterprise con autenticación RADIUS
  • VPN obligatoria para acceso remoto
  • Sin acceso público

Los datos médicos son sensibles. Una filtración puede generar demandas y pérdida de licencia.

Red 2: WiFi de sala de espera

  • SSID público (“ClinicaX WiFi”)
  • Portal cautivo con términos
  • Aislamiento de clientes
  • Límite de ancho de banda (5-10 Mbps por dispositivo)
  • Sin acceso a red médica

Red 3: Administrativa

  • Para personal no médico (recepción, contabilidad)
  • Acceso limitado a ECE y PACS
  • Filtrado de contenido

Trampas comunes en internet para clínicas

1. Usar internet residencial barato

Un plan de Megacable 50 Mbps por $299/mes no soporta PACS ni múltiples videollamadas. Mínimo 100 Mbps fibra simétrica para consultorio pequeño.

2. No separar red médica de WiFi de espera

Si un paciente entra al WiFi compartido, puede intentar acceder a tu red médica. VLAN y redes separadas siempre.

3. Subestimar el consumo de PACS

Subir una resonancia magnética de 500 MB requiere ancho de banda. La subida es crítica, por eso la fibra simétrica es obligatoria.

4. No tener plan de respaldo

Si el internet cae, no puedes acceder a expedientes ni PACS. Hotspot celular de respaldo (Telcel/AT&T) para emergencias.

5. No cifrar el acceso remoto

Médicos que acceden al ECE desde casa deben usar VPN. Nunca exponer sistemas médicos directamente a internet.

Preguntas Frecuentes

¿Qué internet necesita una clínica en México?

Mínimo 100 Mbps fibra simétrica para consultorio pequeño, 500 Mbps fibra simétrica para clínica mediana, 1 Gbps o enlace dedicado para hospital. Totalplay fibra es el mejor por estabilidad y subida simétrica. Usa planes empresariales con SLA para clínicas críticas.

¿Cuánto cuesta internet para clínica?

Entre $399 y $899 MXN/mes por planes residenciales premium de fibra simétrica. Para planes empresariales con SLA: $1,200-$5,000 MXN/mes. La inversión protege datos médicos sensibles y mantiene operaciones críticas como PACS y videollamadas.

¿Por qué es crítica la fibra simétrica en clínica?

Porque las clínicas suben tantos datos como bajan: PACS (imágenes médicas), videollamadas, respaldos de expedientes. La fibra simétrica de Totalplay garantiza 500 Mbps de subida, mientras que el cable coaxial solo ofrece 10-50 Mbps de subida.

¿Es seguro usar WiFi para expediente clínico?

Solo con configuración adecuada: WPA3 Enterprise, VLAN separada, VPN para acceso remoto, y estaciones por cable Ethernet siempre que sea posible. Nunca uses WiFi público o compartido para datos médicos sensibles.

¿Qué pasa si se cae el internet en mi clínica?

No podrás acceder a expedientes electrónicos ni PACS, las videollamadas se cortarán, el TPV no procesará pagos. Ten un hotspot celular de respaldo para mantener operaciones críticas (TPV y ECE básico) durante cortes.
