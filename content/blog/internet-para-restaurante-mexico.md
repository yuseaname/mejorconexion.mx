## Respuesta Rápida

**Un restaurante en México necesita mínimo 100 Mbps fibra para operar TPV (terminal de pago), sistema de gestión (POS), WiFi para clientes y streaming de música sin cortes. El mejor proveedor es Totalplay fibra simétrica desde $399 MXN/mes por 200 Mbps, que evita saturación en horario pico cuando más clientes hay. Para restaurantes medianos (50-150 lugares) recomiendo 300-500 Mbps simétrico ($449-$549/mes). Para grandes (150+ lugares), considera enlaces dedicados empresariales desde $1,500-$3,000/mes.**

- **Mínimo viable**: 100 Mbps fibra para restaurante pequeño (30-50 lugares) = $399 MXN/mes
- **Recomendado**: 300-500 Mbps fibra simétrica para 50-150 lugares = $449-$549 MXN/mes
- **Mejor proveedor**: Totalplay fibra por estabilidad y ausencia de saturación
- **Crítico**: red separada para TPV/POS vs WiFi de clientes (seguridad y rendimiento)
- **Acción**: configura QoS en tu router para priorizar TPV sobre streaming

## Por qué el internet es crítico para un restaurante

Un restaurante moderno depende del internet para:

1. **TPV (terminal de pago)**: procesa tarjetas de crédito/débito. Si el internet cae, no puedes cobrar.
2. **Sistema POS**: gestión de órdenes, inventario, facturación electrónica (CFDI).
3. **Reservaciones online**: plataformas como OpenTable, Google Reservas.
4. **Delivery apps**: Uber Eats, Rappi, Didi Food requieren conexión constante.
5. **WiFi para clientes**: hoy es esperado, especialmente en cafés y restaurantes de cadena.
6. **Música ambiental**: Spotify Business, Apple Music o servicios comerciales.
7. **Cámaras de seguridad**: muchos sistemas IP dependen del internet para grabación en nube.

Si el internet se cae en horario pico (viernes o sábado noche), pierdes ventas. Un restaurante pequeño puede perder $5,000-$20,000 MXN por una caída de 2 horas.

## Configuración crítica: red separada

### Red 1: Operaciones (TPV, POS, cámaras)

- **SSID oculto**, contraseñа fuerte
- **VLAN separada** o red física distinta
- **Ancho de banda garantizado** (configura QoS)
- **Sin acceso de clientes**

Esto protege tus operaciones de pago y datos sensibles. Si un cliente hackea tu WiFi compartido, puede acceder a tu sistema POS.

### Red 2: WiFi de clientes

- **SSID público** ("RestauranteX WiFi")
- **Portal cautivo** (aceptar términos)
- **Límite de ancho de banda** (5-10 Mbps por dispositivo)
- **Aislamiento de clientes** (no pueden verse entre ellos)

Lee más sobre redes seguras en [seguridad WiFi](/blog/seguridad-wifi-casa-mexico.html).

### Red 3: IoT y música (opcional)

- **Dispositivos inteligentes** (termostatos, luces)
- **Streaming de música** ambiental
- **Aislada de operaciones y clientes**

## Trampas comunes

### 1. Compartir red entre TPV y clientes

Un cliente descargando algo grande puede trabar tu TPV y no poder cobrar. **Redes separadas siempre.**

### 2. Usar WiFi de cocina para TPV

El WiFi es menos estable que cable Ethernet. **Conecta tu TPV por cable** siempre que sea posible.

### 3. No tener plan de respaldo

Si el internet principal cae, no puedes cobrar tarjetas. **Ten un plan B** con un hotspot celular (Telcel/AT&T) para emergencias.

### 4. Subestimar la carga de cámaras IP

20 cámaras IP pueden consumir 50-100 Mbps. **Considera esto al elegir plan** o graba localmente sin subir a la nube.
